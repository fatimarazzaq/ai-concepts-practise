## 🧠 What Are Embeddings?

Embeddings are numerical representations of data, such as text, images, or audio.

In natural language processing, an embedding model converts text into a vector of numbers that captures useful semantic information.

For example:

```text
Text
  ↓
Embedding Model
  ↓
Numerical Vector
```

Example:

```text
"I love learning Python."
        ↓
[0.12, -0.43, 0.81, ...]
```

The vector above is illustrative. Actual values are generated by the embedding model.

Texts with similar meanings often have vectors that are close together in the embedding space.

### Why Are Embeddings Useful?

Embeddings are used in:

- Semantic search
- Recommendation systems
- Document retrieval
- Retrieval-Augmented Generation (RAG)
- Clustering similar text
- Duplicate and similarity detection

---

## 🔢 What Is a Vector?

A vector is an ordered list of numerical values.

For example:

```python
vector = [0.12, -0.43, 0.81, 0.25]
```

Each embedding model generates vectors with a particular number of dimensions.

In this project, the `all-MiniLM-L6-v2` model generates **384-dimensional embeddings**.

```text
Sentence
   ↓
Embedding Model
   ↓
384-dimensional Vector
```

Each dimension contributes to the model's learned representation. Individual dimensions generally do not have simple, human-readable meanings.

### Step 4: Calculate Semantic Similarity

```python
from sentence_transformers import util

similarities = util.cos_sim(
    embeddings,
    embeddings
)

print(similarities.round(decimals=3))
```

This produces a similarity matrix comparing each sentence with every other sentence.

**What to observe:**

- Each sentence compared with itself should have a similarity score close to `1.0`.
- Sentences with related meanings may have higher similarity scores.
- Unrelated sentences will often have lower similarity scores.

Similarity scores are not probabilities, and their interpretation depends on the model and data.

### Step 5: Build a Semantic Search Engine

```python
from sentence_transformers import util

documents = [
    "Python is a programming language.",
    "Machine learning helps computers learn patterns.",
    "Pizza is a popular Italian food.",
    "Neural networks are used in deep learning.",
    "Python is widely used for AI development."
]

# Convert documents into vectors
document_embeddings = model.encode(documents)

# Create a search query
query = "How can I use Python to build AI applications?"

# Convert the query into a vector
query_embedding = model.encode(query)

# Compare the query with every document
scores = util.cos_sim(
    query_embedding,
    document_embeddings
)[0]

# Sort documents by similarity
results = sorted(
    zip(documents, scores.tolist()),
    key=lambda item: item[1],
    reverse=True
)

# Display the top 3 results
for document, score in results[:3]:
    print(f"{score:.3f} | {document}")
```

### Expected Result

The search should generally rank Python-related documents near the top because their meanings are relevant to the query.

Exact scores and ranking can vary with the model and document wording.

## 📐 Cosine Similarity

Cosine similarity measures the cosine of the angle between two vectors.

It is commonly used to compare text embeddings.

The formula is:

\[
\text{similarity}(A,B)=
\frac{A\cdot B}{\|A\|\|B\|}
\]

Where:

- \(A\) is the first vector.
- \(B\) is the second vector.
- \(A\cdot B\) is their dot product.
- \(\|A\|\) and \(\|B\|\) are their magnitudes.

For nonzero vectors, cosine similarity ranges from `-1` to `1`.

In practice, many text embedding comparisons produce positive scores.

A higher score often indicates greater semantic similarity, but the score is not a universal measure of meaning.

## 🔍 Semantic Search vs Keyword Search

| Keyword Search | Semantic Search |
|---|---|
| Matches words or terms | Compares vector representations |
| Often depends on exact wording | Can find related meanings |
| Useful for exact identifiers | Useful for natural-language queries |
| Can miss synonyms | Can retrieve relevant paraphrases |

Example:

**Query:**

```text
How do I create AI applications?
```

**Document:**

```text
Python is widely used for AI development.
```

A semantic search system may retrieve this document even though the wording differs.

## 🏗️ How Embeddings Connect to RAG

Embeddings are one of the key components of Retrieval-Augmented Generation (RAG).

```text
Documents
    ↓
Embedding Model
    ↓
Document Vectors
    ↓
Vector Database
    ↓
Similarity Search
    ↓
Relevant Documents
    ↓
LLM
    ↓
Answer
```

Embeddings help identify relevant information. A vector database stores and retrieves vectors efficiently, while an LLM can use the retrieved information to generate an answer.
