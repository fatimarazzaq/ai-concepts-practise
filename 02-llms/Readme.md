# Day 3 — LLMs

## Goal

Build a simple CLI chatbot using an LLM API and Python.

## What I learned

### 1. LLM

An LLM is a language model that can understand and generate text.

### 2. API

Python can communicate with an LLM through an API.

The basic flow is:

Python → API → LLM → Response

### 3. Environment Variables

I stored my API key in a `.env` file instead of putting
the key directly inside the Python code.

### 4. System Message

The system message defines how the AI should behave.

Example:

"You are a helpful Python teacher."

### 5. User Message

The user's question is added to the conversation history.

### 6. Assistant Message

The response generated by the LLM is also added to the
conversation history.

### 7. Conversation History

The chatbot stores previous messages so that later questions
can have context from the earlier conversation.

The structure is:

system
user
assistant
user
assistant
user

### 8. LLM Response

The API returns the model's generated response, which I display
in the terminal.

## Conversation Flow

User
↓
Python
↓
LLM API
↓
LLM
↓
Response
↓
Conversation History
↓
Next User Question

## Experiments

I changed the system instructions and observed how the model's
responses changed.

For example:

- Python teacher → simple explanations
- Senior Python engineer → more technical explanations

## What I built

A command-line chatbot that:

- Reads an API key from an environment variable
- Has a system message
- Accepts user input
- Sends messages to an LLM
- Displays the response
- Maintains conversation history
- Supports multiple questions in one conversation
